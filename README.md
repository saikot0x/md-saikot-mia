# Md Saikot Mia — Cyber Security & Networking Portfolio

A portfolio built for cyber security / networking internships and junior SOC / analyst roles.

Live: https://saikot0x.github.io/md-saikot-mia/

## Structure

```
index.html
css/style.css
js/early.js  js/data.js  js/main.js
images/      favicon, apple-touch-icon, og-image, profile
resume.pdf  robots.txt  sitemap.xml
```

All site content (projects, skills, experience, TryHackMe stats) lives in `js/data.js`.
When you change a CSS or JS file, bump the `?v=` number in `index.html` so browsers reload it.
